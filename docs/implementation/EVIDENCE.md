# Evidence and research navigation

This is the current index, not another session log. Exact source, image,
measurements, observations and cleanup belong in dated receipts; implementation
status and the next authorized action belong in [TRACKER](TRACKER.md) and
[status](../status.md).

## Evidence levels

| Evidence | Establishes | Does not establish |
| --- | --- | --- |
| Kernel/adapter tests and sanitized vectors | Specified arithmetic, parsing, identity and transition behavior | Authentic live source data, complete venue semantics or production policy |
| Joined SDK/service tests | Real component composition under explicit external fixtures | Actual venue funding or AWS attestation |
| Compiled local SBF/Surfpool | Executed custody instructions, constraints, CPI rollback and payment counters | Devnet/mainnet deployment or native venue credit |
| Exact-image Nitro run | Its measured code, role release, channels, storage and recorded checks | Later code or every financial workflow |
| Native testnet receipt | Original observed actions and limits in that invocation | Mainnet parity, fee guarantees or customer-funds readiness |
| Merkle claim evidence | Membership and the program's checked payment context | Completeness of liabilities, solvency or unconditional recovery |
