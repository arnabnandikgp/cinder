# Public known-answer fixture

The single NK vector in `src/known_answer.rs` is extracted from Snow 0.10.0's
`tests/vectors/cacophony.txt`; its expected output is not generated by Cinder.
All deterministic keys are public fixtures. The wrapper does not permit early
payloads, although this standard library vector intentionally exercises them.
The package archive checksum and upstream source are recorded in that file.
